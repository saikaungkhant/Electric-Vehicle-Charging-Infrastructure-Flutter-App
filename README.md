# EV Charging Infrastructure App

A cross-platform Flutter application that helps electric vehicle drivers locate nearby charging stations and supports geospatial analysis of charging infrastructure placement. Built as a group project during my MSc Data Science studies.

## My Contribution

This was a team project. My focus was the **database layer and frontend development**, plus leading the **geospatial and business-function analysis** using Uber's H3 Grid System to model optimal charging station placement and demonstrate potential ROI. Backend API services were built by a teammate using Flask.

## Tech Stack

- **Frontend:** Flutter (cross-platform: Android, iOS, macOS, Windows, Web)
- **Database:** MongoDB (accessed via the `mongo_dart` package)
- **Maps & Location:** Google Maps Flutter, Geolocator
- **Backend API:** Flask (built by teammate)
- **Geospatial analysis:** Uber H3 Grid System

## Features

- User registration and login, with OTP verification
- Interactive map view showing nearby charging stations, using real charge point registry data (device name, location, coordinates)
- Nearest-station lookup based on the user's current location
- Data pulled from and written to MongoDB directly from the Flutter client

## Status

This was a time-boxed academic group project. It is not actively maintained, and some platform-specific build configurations (iOS, macOS) were generated by Flutter tooling and have not been fully tested on physical devices.
